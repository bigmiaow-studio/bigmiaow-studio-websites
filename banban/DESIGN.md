# 伴伴 visual system
A flat, playful Chinese collaboration brand. Warm yellow #fdc700 carries the featured story and invitation band; navy #0f172b grounds the contrast story. White cards sit on #fafafa with restrained #e4e4e4 borders. Pink #ff637e is a small expressive accent.

Typography: Noto Sans SC 400–900. Desktop display 58px; mobile display 39px; testimonial text 20–26px. Rounded cards use 16px corners, inputs/buttons 7–8px. Main content aligns to equal 56px desktop edges, 20px mobile edges.

The page leads with the exact heading “他们这样说”, then category tabs and six story cards. Desktop grid has three columns, tablet two, mobile one. The first card is yellow; the third is navy. The yellow invitation leads into a four-column footer that stacks on mobile.

Interactions: Radix Tabs for filtering, Dialog for full stories and local form, Sheet for mobile navigation. Intro reveals once, decorative mark turns once, cards lift on hover. Reduced-motion disables animation. Keyboard focus uses a visible green outline. Illustrative portrait assets are from Unsplash and all example testimonials are labeled as such.
