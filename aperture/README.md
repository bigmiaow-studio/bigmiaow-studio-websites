# Aperture

**在线预览：**[打开 Aperture](https://bigmiaow-studio.github.io/bigmiaow-studio-websites/aperture/)

为协作式 AI 工作空间 **Aperture** 制作的单页概念官网。视觉围绕「超现实手撕纸洞拼贴 × 纯白社论排版 × 天蓝单重点色」展开，使用原创无字拼贴画板、古典大理石雕塑和明暗天空，展示团队与 AI 协作的可能性。

网站采用原生 HTML、CSS 和 JavaScript，**100% 离线运行**，无构建步骤、运行时依赖或外链 CDN。

## 本地运行

下载本目录，保留目录结构，直接使用浏览器打开 [`index.html`](index.html) 即可。无需安装依赖或启动服务器。

## 页面与交互

- **首屏**：全宽晴空手撕纸洞与大理石雕像拼贴、悬浮导航、社论标题、双胶囊 CTA，以及六格细线虚构合作团队条。
- **能力展示**：`Outreach / Automation / Analytics / Sync` 四个标签联动标题、说明、2×2 能力网格和 `Interactions` 柱状图。每根柱子可单独选择；标签支持方向键、Home 和 End 键。
- **人类判断**：多层白纸撕洞、深钴蓝夜空与大理石手雕塑拼贴，叠加 AI 评审浮卡。支持展开三条建议、逐项开关、`Approve / Undo` 审批状态切换；全部关闭时停用审批按钮。
- **收尾**：星河与手撕云层 CTA 卡、无边框白色页脚。所有 CTA 在页面内跳转。
- **响应式与辅助功能**：手机折叠菜单、键盘焦点、跳过导航入口和减少动态效果设置支持。

团队名称、图表数值和展示指标均为概念演示内容，页面页脚已注明。审批交互只改变本地演示状态，不会向远程服务发送文档。

## 设计与资源

- 重点色：`#1D7DFA`，搭配纯白和深色正文。
- 标题：本地 **Playfair Display**，仅用于 H1/H2，当前使用字重 400。
- 正文与交互：本地 **Manrope** 可变字体。
- 图像：通过内置图像生成工具制作的四张原创无字画板；页面使用 WebP，保留完整 PNG 原图。
- 字体授权：字体目录中附有两种字体各自的 SIL Open Font License。
- 图像生成记录：[`assets/images/provenance.json`](assets/images/provenance.json) 保存四张画板的完整生成提示词与文件对应关系。
